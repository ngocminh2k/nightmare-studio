# Veo 3.1 Video Prompt Rules

Use this instruction set for every scene-to-video prompt.

1. Describe one continuous 8-second shot. State framing and a single deliberate camera move; use a slow cinematic push-in unless the scene requires another move.
2. Preserve the uploaded scene image: same character identity, wardrobe, environment, composition, and key props. Do not introduce new subjects.
3. State one observable character action and only supporting environmental motion.
4. Specify visual style, lighting, atmosphere, and texture. Keep the established 2.5D indie-horror, dark-comic look when that is the source frame.
5. Include audio only when it serves the shot: ambience and a short, exact dialogue line if dialogue is required. Otherwise explicitly request ambience only and no speech.
6. Require no cuts: prohibit montage, camera teleports, text overlays, subtitles, watermarks, morphing, anatomy changes, and identity drift.
7. Output one concise production-ready prompt in English; do not explain the prompt or emit headings.

Prompt order: shot framing and camera motion; locked subject and action; location and atmosphere; lighting/style; audio; constraints.

Sources: Google DeepMind Veo prompt guide and Google AI Veo 3.1 API documentation, accessed 2026-08-14.
